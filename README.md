# NOVA MART — Saudi Bilingual Retail Demo

A premium React + Tailwind CSS demo designed for Saudi retail shops that want to sell through WhatsApp.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Included

- 10 routes/pages
- English + Arabic language switch
- Arabic RTL support
- 120 demo products
- SAR pricing from 5–50
- Search
- Category filtering
- Price filtering
- Sorting
- Product details
- Wishlist
- Shopping cart
- WhatsApp order generation
- Offers
- New arrivals
- Responsive mobile-first design

## Change the WhatsApp number

Search the project for:

`966500000000`

Replace it with the shop owner's Saudi WhatsApp number.

## Change the brand

Search for:

`NOVA MART`

and replace it with the client's business name.

## Change products

All demo products are in:

`src/data/products.js`

## Deploy to Vercel

```bash
npm run build
```

Upload the project to GitHub and import the repository into Vercel.
